# Cautious behavior and movement update

Current build label: **Foundation 4 / cautious movement**. New encounters use `encounter-prototype-4`.

## What changed

Previously, Cautious was only a stress label: positive bravery/support could still select Fight and route a human directly toward a zombie. New runs add an awareness boundary to that action. Aware/Cautious humans with a positive courage margin now watch at a distance and back away within three cells. On contact they may still perform a defensive shove. Existing Freeze and Flight thresholds remain. Higher-intensity deliberate Fight can still approach; the controlled Fight scenario starts Alarmed so it demonstrates that behavior. Group Support now demonstrates support without turning cautious humans into automatic attackers.

The old renderer blended a move over one tick (0.2 seconds), although actors move only once every five ticks (one second). It then held the endpoint for the rest of the interval. The new presentation keeps an ordinary step moving steadily across the full five-tick interval. Small stable within-cell offsets reduce identical center alignment without changing simulation randomness. Pursuit prefers direct steps among equivalent local routes, and retreat scores alignment per unit distance instead of favoring diagonals merely because their cell displacement is larger.

**Movement and collision still use an eight-neighbor grid.** This update reduces pauses, alignment and gratuitous zigzags; it does not implement continuous navigation or arbitrary steering angles. Ordinary visible motion can trail the committed simulation cell by up to one movement interval. Pause and manual stepping synchronize to exact committed positions for inspection. Load/resume/placement also reset presentation safely. Interrupted or compound pushes and unsafe corner transitions synchronize to canonical endpoints rather than smoothing a shortcut through a wall. Native visual quality still needs checking in Unity.

## Use the update

Download the latest project using GitHub **Code > Download ZIP**, extract into a new folder and open **OutbreakRebuild** in Unity 6. Choose **Outbreak > Rebuild > Open and Run Foundation**.

- Choose **Start Encounter** for the new rules immediately.
- Load an existing prototype-three reaction run and click **Use cautious behavior** in the simulation toolbar to upgrade it explicitly. The run remains paused, with actor identities, infection/freeze timing, clock and random streams preserved. The original save file is untouched; save under a new name if you want to preserve both rule versions.
- Without that explicit upgrade, earlier saves retain their original behavior. Prototype-one/two saves remain under their earlier rules; begin a new encounter to use current human reactions.
- Main Menu, Resume current run and exact 1/10/50/100-tick controls remain available.

The v3 compatibility reference in Tests/Fixtures was generated by executing production source from commit ee3e24d84eec0782b81235eb12d7106decc1a939: HumanResponse(Fight), override initial human stress to 22, restore, step once and capture; step 100 more times and capture the expected continuation. Expectations were not generated from the new movement rules.
