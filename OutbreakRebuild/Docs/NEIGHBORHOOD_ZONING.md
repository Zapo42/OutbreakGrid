# Foundation 117 — neighborhood zoning and store placement

In **Set Up Generated City**, click **Zoning: Fixed layout** to select **Neighborhood centers**, then start a new city. It works with Grid or Neighborhood streets and either residential density. **Inspect Zoned Neighborhood Paused** opens a standard two-house neighborhood using the new zoning directly. Fixed layout remains the default and retains its previous generation policy.

Previously, commercial roles were fixed at block indices 0 (distribution center), 2 and 6 (stores, when present). Neighborhood centers zoning chooses a seeded corner for the distribution center, then evaluates store locations among the remaining blocks. It first minimizes the farthest residential block's distance to its nearest store, then total residential distances, then estimated distribution-to-store distances. Seeded ties allow different arrangements without changing the counts or consuming encounter random streams.

Distance is measured in orthogonal block steps, not exact NPC walking time. In the standard 4×2 layout every residential block borders a store block, reducing the previous worst two-block separation to one. Larger layouts spread stores to cover more of the town. Actual doors, crosswalks, pedestrian links, obstacles, danger, hunger and energy still determine real trips. This is placement groundwork, not a guarantee that every store always has stock or that an NPC knows an unseen shop.

Stores face toward the nearby home blocks they serve, using the direction of those households as an entrance-facing preference. The distribution entrance faces toward the residential town. Existing per-building footprint sizes, enclosed rooms and connected entrance paths remain. Residential lots retain their previous footprint/facing policy, including paired homes on dense blocks. Streets, crosswalks and their shared road-surface classification are unchanged.

The number of homes, stores, staff and starting meals stays the same for each size/density. Workers still have separate homes, start at work and use existing shifts. The courier remains first in the actor list even when the distribution center moves to a later block. Clerks remain attached to their actual stores and phones. Consumers retain observation-based shop and stock knowledge; generation does not reveal inventories to them.

New zoned terrain uses city-zoned-lots-1. Existing saves retain actual geometry, designations, assignments, inventories and active jobs. Restart restores their recorded start rather than rerunning zoning. Simulation rules remain encounter-prototype-90; no saved-run upgrade is needed to keep playing. Create a new city to see the new placement option.

Tests cover site counts, peripheral center placement, seeded variation, improved worst-distance coverage over the fixed policy across supported rectangles/seeds, entrances facing served neighborhoods, furnished doorway access, unique housing, finite supplies, deterministic generation, clerk requests, exact saved continuation, minimum/maximum catalogs and both street/density options. UI API doubles cover the setup choice, preview, paused start and restart. Unity 6000.6.3f1 native rendering, layout, input and performance remain unverified; the Foundation 82 checkpoint is unchanged.

This first zoning step retains one distribution center and one or two food stores. Flexible store counts, specialized supply/medical/ammo stores, industrial districts and larger household populations remain later steps. Current storage remains food-only, without weapons in boxes.
