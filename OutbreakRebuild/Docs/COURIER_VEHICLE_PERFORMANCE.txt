Foundation 124 courier-vehicle core benchmarks

Same Linux cloud environment, .NET 8 Release, median of three runs after separate JIT warmup.
Runs were sequential after the acceptance/UI suites. Only simulation ticks are timed;
setup, serialization and Unity rendering/input are excluded. No native FPS claim is made.

Complete courier preview workload (covers both initial shipments and return travel):
Courier vehicle: 5 residents, 1 van: 2500 ticks median 341.5 ms (0.137 ms/tick), allocated 11.96 MiB; exact continuation PASS. Core only; Unity rendering excluded.

All three repetitions matched exact final saved states. Tests separately compare live continuation
against a fresh save/load during walking, boarding, driving, unloading and return phases.
Shared road-distance fields are derived and rebuilt after load; food/order/RNG/clock state is saved.

Actual Unity/Windows performance, heavy multi-vehicle traffic and large outbreaks remain unverified.
