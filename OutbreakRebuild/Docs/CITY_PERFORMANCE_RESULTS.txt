Foundation 122 city performance measurements

Same Linux cloud environment, .NET 8 Release, median of three 500-tick runs after JIT warmup.
Simulation ticks only; creation, serialization and native Unity rendering excluded.
No concurrent benchmark or core-test process ran during these final measurements.
Timings vary by machine and load. These are not Unity FPS measurements.

Matched Foundation 121 saved worlds (seed 214), label columns-rows-homesPerBlock:
The before source is a temporary copy of Foundation 121 core, with aggregate route-timer instrumentation.
Both revisions load the same starting JSON and must match the exact same final JSON, including RNG.

BEFORE (Foundation 121):
4-2-2: 500 ticks median 359.8 ms (0.720 ms/tick), allocated 18.40 MiB; exact continuation PASS. Core only; Unity rendering excluded.
6-5-2: 500 ticks median 786.1 ms (1.572 ms/tick), allocated 34.25 MiB; exact continuation PASS. Core only; Unity rendering excluded.
6-6-1: 500 ticks median 501.6 ms (1.003 ms/tick), allocated 23.87 MiB; exact continuation PASS. Core only; Unity rendering excluded.

AFTER (Foundation 122):
4-2-2: 500 ticks median 202.0 ms (0.404 ms/tick), allocated 1.72 MiB; exact continuation PASS. Core only; Unity rendering excluded.
6-5-2: 500 ticks median 271.1 ms (0.542 ms/tick), allocated 16.24 MiB; exact continuation PASS. Core only; Unity rendering excluded.
6-6-1: 500 ticks median 204.1 ms (0.408 ms/tick), allocated 7.83 MiB; exact continuation PASS. Core only; Unity rendering excluded.

For the 54-resident 6x5 dense city: 786.1 -> 271.1 ms, 2.90x throughput / 65.5% less tick time.
Managed allocations: 34.25 -> 16.24 MiB, 52.6% lower.
For the other matched cities: 1.78x and 2.46x throughput respectively.
